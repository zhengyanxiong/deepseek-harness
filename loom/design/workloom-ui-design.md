## 1. 目标与边界

### 1.1 目标

1. 创建项目、版本、任务统一为**居中弹框**，不再使用右侧抽屉。
2. 弹框顶部固定步骤条，让用户始终知道当前步骤和剩余步骤。
3. 统一按钮层级，一屏只保留一个主操作，删除收进溢出菜单或确认框。
4. 主界面采用可扫描的三段结构：左栏导航、中间工作台、右栏上下文；底部是可展开的 Diff/审计区。
5. 右栏完整展示所有仓库、Lock、版本 ref、工作区分支；分支只读，不在这里切换。
6. 右栏模块、测试、用量默认展开，信息多时只纵向滚动，不折叠、不横向滚。
7. 面板宽度/高度通过边界拖动调整，已有实现保留，不引入“宽度滚动条”。
8. 看板按项目泳道和业务状态列展示任务，右栏显示看板概览，和主界面共用一套视觉语言。
9. 不改变现有 Remote 请求、领域状态和持久化格式；只改呈现和交互。

### 1.2 非目标

- 不新增第三方 UI 框架，不引入 Ant Design。
- 不改任务执行、Lock、工作区、审计的后端行为。
- 不新增终端和测试集成；底部“终端 / 测试”仍是占位，等后续接线。
- 不重写 Workloom 的品牌标识和插件图标。
- 不在右栏提供分支切换、删除、清理等危险操作；这些去编辑工作区或确认弹框。

## 2. 设计原则

1. **安静的层级**：浅灰侧表面、白色工作区、1px 发丝线；不使用大面积深色块和重阴影。
2. **结构信息用等宽**：hash、分支、时间、数量、路径、成本数字用 mono；业务标题用无衬线。
3. **状态不只靠颜色**：状态点 + 文字；失败、运行、待审核都必须有文字。
4. **一屏一个主操作**：Workbench 的黑色主按钮是“开始执行 / 打开会话”；创建弹框的主按钮是“下一步 / 创建”；看板不额外放黑色按钮。
5. **右栏只读优先**：分支、Lock、工作区状态是观察对象，不是操作区；需要修改就去编辑。
6. **展开优于折叠**：模块、测试、成本默认展开；不用“摘要行 + 展开”增加一次点击。
7. **边界拖动不是滚动条**：右栏往左拉、底部往上拉；没有用于调宽的水平滚动条。
8. **密度可控**：1440 是基准；窄宽度优先截断和换行，不出现面板级横向滚动。

## 3. 视觉系统

### 3.1 颜色

| 用途 | token / 建议值 | 说明 |
|---|---|---|
| 画布 | `--dsw-alias-bg-base` / `#F3F4F6` | 页面底色 |
| 主表面 | `--dsw-alias-bg-layer-1` / `#FFFFFF` | 工作台、卡片、弹框 |
| 侧表面 | `--dsw-alias-bg-layer-2` / `#FBFBFC` | 左右栏、底部标签栏 |
| 凹面 | `--dsw-alias-bg-layer-3` / `#F0F2F5` | 选中、分段控件、计数 chip |
| 边框 | `--dsw-alias-border-l4` / `rgba(15,17,21,.10)` | 发丝线 |
| 强边框 | `--dsw-alias-border-l3` | 输入框 hover/focus 外侧 |
| 主文字 | `--dsw-alias-label-primary` / `#0F1115` | 标题、正文 |
| 次文字 | `--dsw-alias-label-secondary` / `#5D636D` | 说明、标签 |
| 弱文字 | `--dsw-alias-label-caption` / `#8B919A` | 计数、时间、路径 |
| 品牌/运行 | `--dsw-alias-brand-primary` / `#4176E6` | 主按钮、进行中、选中线 |
| 完成 | `--dsw-alias-state-success-primary` / `#48A363` | 已完成、工作区活跃 |
| 警告 | `--dsw-alias-state-warn-primary` / `#D6A23A` | 有未提交改动、优先级高 |
| 失败 | `--dsw-alias-label-error` / `#C45151` | 失败、危险操作 |
| 待审核 | `#8B6FD6` | review 状态 |
| 选中底 | `#F0F5FD` | 左树选中、分段选中底色 |

规则：
- 品牌蓝只用于重点操作、选中、运行态，不做大面积背景。
- 深色主按钮使用 `#0F1115`，hover `#25282E`；不把品牌蓝做成主按钮。
- 危险红默认只出现在文案和确认按钮；不要整块红色背景。
- 侧栏和工作台之间用发丝线分隔，不用阴影。

### 3.2 字体与字号

| 层级 | 规格 | 用途 |
|---|---|---|
| 页面/弹框标题 | 16–18px / 500 | 版本名、弹框标题 |
| 卡片/任务标题 | 12px / 500 | 任务名、卡片标题 |
| 正文 | 11.5–12px / 400–500 | 描述、字段值 |
| 说明 | 10.5–11px | 提示、错误、次级信息 |
| 微标签 | 8.5–10px / mono | kicker、计数、hash、时间 |
| 数字 | mono 400，必要时 13–16px | 成本、卡片数、统计 |

规则：
- 标签用 8.5–10px 大写 mono + 字间距 `.06em`；中文标签不用全大写，只在英文 kicker 上使用。
- 长路径允许折行；分支名单行截断并设置 `title`；任务标题最多两行。
- 正文最小 11px；8.5–9px 只用于 mono 元数据，不用于可读正文。

### 3.3 间距、圆角、边框、阴影

| 项 | 值 |
|---|---|
| 间距阶梯 | 4 / 6 / 8 / 10 / 12 / 14 / 16 / 24 |
| 圆角 | 输入/按钮 6–8；卡片 7–8；弹框 12–14；分段 6 |
| 边框 | 侧栏/分区 1px；卡片内部分隔 0.5–1px |
| 阴影 | 页面无阴影；弹框 `0 24px 64px rgba(0,0,0,.5)`；悬停卡片可 0–1px |
| 点击区 | 图标按钮最小 26×26；主按钮 36px 高；移动/触屏 32px 以上 |

### 3.4 状态与优先级

| 状态 | 点色 | 文案 | 使用 |
|---|---|---|---|
| pending | `#AEB5C0` | 待开始 | 列头、卡片左线、左树 |
| running | `#4176E6` | 进行中 | 列头、左树、活跃会话 |
| review | `#8B6FD6` | 待审核 | 列头、卡片、审核队列 |
| completed | `#48A363` | 已完成 | 列头、左树 |
| failed | `#C45151` | 失败 | 列头、卡片 |

| 优先级 | 文案 | 建议色 |
|---|---|---|
| low | 低 | 弱灰 |
| normal | 普通 | 青灰 `#2D7C85` |
| high | 高 | 琥珀 `#9A6B12` |

- 状态点 5px；任务左线 2px；状态标签不要做成大色块。
- 模块、版本、Lock、成本等用 mono，避免和业务标题抢层级。

## 4. 主界面外壳

### 4.1 尺寸

基准画布 1440 宽；下表中的“设计值”是实施目标，括号内为当前代码需要调整的现状。

| 区域 | 设计值 | 说明 |
|---|---|---|
| 顶栏 | 52px | 固定；项目/版本/视图/新建/面板开关 |
| 左栏 | 320px 固定 | 项目树、会话、底部创建；不可拖 |
| 中间 | 自适应 | Workbench 或看板 |
| 右栏 | 344px 默认 | 320–460；默认展开 |
| 右栏预览态 | 300–720 | 文件预览/Diff 预览时独立宽度 |
| 底部折叠条 | 34px | 收起状态 |
| 底部展开高度 | 220px 默认 | 80–320 |
| 面板圆角/边框 | 0 | 外壳内区域用直线和发丝线，不做卡片嵌套 |

窄屏：
- `>1180`：完整三栏。
- `941–1180`：左 320，右 320–380，中间最小 480；过滤器和卡片元数据可减少。
- `≤940`：左栏改为覆盖抽屉，右栏限制在 300 左右；顶栏隐藏项目/版本文字标签；不再强行三栏。
- 弹框宽度不超过 `calc(100vw - 32px)`；高度不超过 `calc(100vh - 32px)`。

### 4.2 顶栏

- 左：品牌标记 + `Workloom`；竖分隔；项目选择器；版本选择器；活跃工作区 `● 2 个工作区`。
- 中：`工作台 / 看板` 分段控件；选中项白底、正文色、轻阴影。
- 右：`+ 新建` 描边次按钮（带下拉）；右侧面板开关；设置；窄屏多一个左栏抽屉开关。
- 项目/版本选择器是**安静的文字选择器**：无厚边框、无大块底色，hover 才出现浅底。
- 顶栏不放删除、清理、接管；这些在右栏溢出菜单或任务执行区。
- 顶栏 `新建` 永远是描边次按钮；黑色主按钮留给当前视图主操作。

### 4.3 左栏

- 竖直分区：置顶项目 → 项目树 → 会话。
- 分区标题 9–10px，数量/版本/时间用 mono；标题行右侧可放“新增版本 / 编辑 / 置顶 / 更多”。
- 项目行 32px；文件夹图标 + 名称 + 版本数；hover 才显示行内操作。
- 版本行用浅蓝 chip；任务行 30–32px，状态点 + 两行文本：任务名、状态。
- 选中任务：2px 蓝色左线 + `#F0F5FD` 底色，不用整块深蓝。
- 会话：搜索框；任务会话分组；最多 5 个提示；底部“新建任务会话 / 新建临时会话”；置顶为空时保留一句“点击项目右侧的置顶按钮”。
- 左栏底部“新建项目”为描边通栏；“新建任务会话”描边通栏；“新建临时会话”弱按钮。
- 左栏固定 320，不提供拖动；这是当前实现的边界，不要在左栏加 resize handle。

### 4.4 中间工作台

从上到下：

1. **任务头**：任务标题（16–18/500），状态 chip、优先级 chip、版本 chip；右侧 `…` 溢出菜单。
2. **TASK / DESCRIPTION**：任务描述卡；字段行显示版本、优先级、模块；长文本折行。
3. **ACCEPTANCE**：验收项列表；未完成空心圆，完成勾选；每项最多两行。
4. **执行**：代码目录、工作区两个字段；状态 badge（执行中/已完成）；一个黑色主按钮：
   - 运行中：`打开会话`
   - 待开始：`开始执行`
   - 完成后：不显示主按钮或弱化为 `查看会话`
5. **RECENT ACTIVITY**：时间 + 事件；最多 2–4 条，完整列表在底部审计。
6. 空态：无项目 → `新建项目`；无版本 → `新建版本`；无任务 → `新建任务`；空态只留一个主操作，不堆插画。

- 任务头不直接放删除；删除在右栏“更多”或左树溢出菜单。
- 执行卡只在当前任务存在时出现；运行中 badge 用蓝点 + 文案，不只靠颜色。

### 4.5 右栏

右栏是当前版本的上下文，不是第二个操作面板。

结构（自上而下）：
1. **标题**：版本名；右上最多两个图标：编辑版本、更多；删除进“更多”。
2. **GIT / 分支**：按仓库逐个列出；每个仓库一张小图。
3. **TASK**：任务名、状态、优先级、当前轮次；标题右侧“编辑”文字按钮。
4. **WORKSPACE**：根目录、按仓库列出的工作区分支、状态（有未提交改动/干净）。
5. **MODULES**：数量 + 模块列表；空态“该项目没有配置模块。”
6. **TESTS**：最近执行结果；空态“本次会话未执行测试。”
7. **COST / USAGE**：未缓存输入、输出、缓存读写、累计；空态“未记录用量。”

规则：
- 模块、测试、用量**默认全部展开**，不做折叠摘要。
- 只允许纵向滚动；禁止面板级横向滚动。
- 工作区分支只读展示；不提供切换、不提供下拉。
- 右栏不放主按钮；“重新生成 Lock”是描边按钮；首次“生成 Lock”可保留主按钮，生成后必须降级为描边。
- 宽度 344 时全部信息应尽量一屏可读；320 时允许纵向滚动，但不得横向溢出。
- 长路径换行；分支/ref 单行截断，`title` 给完整值；标签不换行。

### 4.6 面板拖动

- **右栏**：左边缘 7px 竖向拖动手柄；向左拉变宽，344 → 460；`cursor: col-resize`。不是滚动条。
- **底部**：展开后上边缘 7px 横向拖动手柄；向上拉变高，220 → 320；向下拉收起；`cursor: row-resize`。
- 拖动中显示手柄/边界高亮；hover 用品牌色；结束后写入偏好设置。
- 左栏固定，不提供拖动。
- 面板内容超出时各自滚动，不能用给布局加横向滚动条的方式“模拟拖动”。

## 5. 按钮与操作体系

### 5.1 层级

| 层级 | 视觉 | 使用场景 | 一屏数量 |
|---|---|---|---|
| Primary | 深色填充 `#0F1115` | 创建、保存、开始执行、打开会话、首次生成 Lock | 1 |
| Secondary | 描边 | 浏览目录、上一步、加载分支、重新生成 Lock | 0–2 |
| Ghost | 无边框 | 取消、返回、关闭、行内文字操作 | 0–N |
| Danger | 红色实心 / 红色描边 | 删除、丢弃改动、停止并接管 | 只在确认框或危险区 |
| Icon | 26–30px 方形 | 编辑、置顶、新增版本、更多、面板开关 | 每行最多 3 |

原则：
- 同一屏最多一个深色主按钮；右栏、左栏、看板不要各放一个。
- 删除永远不和主操作并排；删除入口在“更多”菜单或左树溢出菜单。
- 纯图标按钮必须有 `aria-label` 和 Tooltip；文字按钮优先用动词开头。
- 危险按钮默认不红；进入确认框后才用 error 色。

### 5.2 尺寸与状态

- 弹框/表单 footer：36px 高，左右 16px padding，圆角 8。
- 左树行内按钮：26×26；右栏标题图标：28×28；顶栏图标：30×30。
- Disabled：保留轮廓，`opacity: .45`，`cursor: not-allowed`。
- Loading：文字改为“创建中… / 保存中… / 生成中…”，按钮禁用，防重复提交。
- Hover/Focus：使用 layer-3 浅底 + 品牌色 outline；不能只改颜色。
- 键盘焦点：`:focus-visible` 清楚可见；弹框内焦点循环。

### 5.3 各区域按钮安排

| 区域 | 主操作 | 次操作 | 弱操作 | 溢出菜单 |
|---|---|---|---|---|
| 顶栏 | 新建（描边） | 面板开关、设置（图标） | — | — |
| 左树项目行 | — | — | 新增版本、编辑、置顶 | 删除项目 |
| 左树底部 | 新建项目（描边通栏） | 新建任务会话（描边通栏） | 新建临时会话 | — |
| 中部引导卡 | 当前步骤主按钮 | 选择已有对象 | 新建项目 | — |
| 中部工作台 | 开始执行 / 打开会话 | — | — | 删除任务 |
| 右栏标题 | — | 编辑版本（图标） | 更多（图标） | 新建版本、删除 |
| 右栏正文 | 首次生成 Lock | 重新生成 Lock | — | — |
| 弹框 footer | 下一步 / 创建 / 保存 | 上一步 | 取消 | — |
| 看板 | 顶栏新建（描边） | 泳道 `+ 新建卡片` 文字 | — | — |

## 6. 创建与编辑

### 6.1 统一弹框外框

所有创建、编辑、导入使用居中 Modal；不再从右侧抽屉出现。

```
┌──────────────────────────────────────────────┐
│ 新建项目                                  ✕  │
│ 4 个步骤 · 第 2 步：登记仓库                 │
├──────────────────────────────────────────────┤
│ ① 基本信息 ─ ② 仓库 ─ ③ 模块 ─ ④ 确认      │
├──────────────────────────────────────────────┤
│ 当前步骤内容（最大高度 60vh，内部滚动）      │
├──────────────────────────────────────────────┤
│ 取消                       上一步  [ 下一步 ]│
└──────────────────────────────────────────────┘
```

尺寸：

| 类型 | 宽度 | 说明 |
|---|---|---|
| 新建项目 | 760px | 仓库行、模块行需要横向空间 |
| 新建版本 | 660px | 每个仓库一行分支选择 |
| 新建任务 | 660px | 文本域和模块列表 |

## 7. 危险操作弹框

### 7.1 危险等级

| 等级 | 视觉 | 操作 | 规则 |
|---|---|---|---|
| 不可逆删除 | 红色实心 | 删除项目/版本/任务 | 默认焦点在取消；按钮带对象名 |
| 丢弃数据 | 红色实心 + 必选确认 | 丢弃改动并清理工作区 | 先看 Diff，再勾选确认，按钮才可点 |
| 中断执行 | 红色描边 | 停止并接管 | 只停止，不删除数据，不用红底 |

### 7.2 删除确认

- 简单删除 460px；依赖阻止 560px。
- 对象卡展示名称、所属版本/项目、状态；不能只显示“确认删除吗？”。
- 可删除：`取消` + 红色实心“删除任务/删除版本/删除项目”。
- 被依赖阻止：列出具体依赖和数量，例如“1 个版本 · 3 个任务”，不提供删除按钮。
- 不级联删除：项目有版本、版本有任务、任务有未清理工作区或运行中执行时都阻止。
- 失败原因留在弹框内；按钮从“删除中…”恢复。
- 删除成功后再关闭并刷新左树/右栏；不在关闭动画前清空选中状态。

### 7.3 清理工作区

- 宽度 880px；左检查摘要，右真实 Diff；内容超出滚动。
- 摘要显示：未提交文件数、未推送提交数、工作区路径。
- 无改动：主按钮黑色“清理工作区”。
- 有改动或未推送提交：危险区勾选“我已知晓，将丢弃这些未提交改动”，主按钮变红色“丢弃改动并清理”；未勾选禁用。
- 运行中的任务禁止清理；阻止态说明先停止或接管。
- 提供放大/还原，不隐藏 Diff，不默认折叠改动。
- 关闭、Esc、取消一致；请求中禁止关闭；失败留内。

### 7.4 停止并接管

- 宽度 440px；显示当前任务和执行所有者 Session。
- 说明“停止当前执行、工具和子 Agent；不会自动提交、重置或丢弃改动”。
- 按钮用红色描边“停止并接管”，不用红色实心；默认焦点在取消。
- 失败信息留弹框内，可重试。

### 7.5 共用行为

- 普通弹框默认焦点在第一个输入或主按钮；危险确认默认在取消。
- Enter：危险确认不触发删除；表单触发主按钮。
- Esc/遮罩：表单有未保存内容先确认；纯确认弹框直接取消。
- 请求中禁用所有操作；主按钮显示进行中文案。
- 失败不关弹框；显示本地化原因和可展开技术详情。
- 关闭后焦点回触发按钮；弹框内焦点循环。

## 8. 右栏：Git 与工作区

### 8.1 多仓库原则

当前项目配置可以包含多个 source。右栏必须**逐个列出所有仓库**，不能只显示第一个仓库。

每个仓库一个块：

```
deepseek-harness-loom                       .
● 4f76ece   Lock
● feature/dsh-loom   [版本] [工作区]

deepseek-harness                 ../deepseek-harness
● a91c2d3   Lock
● main   [版本] [工作区]
```

- 仓库名左侧无长路径；路径靠右、允许单行截断。
- Lock 用黑点 + commit hash；版本 ref 用蓝点；工作区 ref 用绿点。
- 同一 ref：合并成一个分色节点，挂「版本 / 工作区」两个标签，不画假分叉。
- 不同 ref：从 Lock 分叉成两条线；版本蓝、工作区绿；只画 ref 关系，不伪造提交历史。
- 多仓库时每个仓库一张小图；区块之间用发丝线分隔。
- 标题右侧显示 `LOCK n 仓库`，不把多个 hash 塞进标题。

### 8.2 只读与 Lock

- 工作区分支只读展示，不提供切换；要改去编辑工作区。
- “重新生成 Lock”是描边按钮；首次生成可用主按钮，生成后必须降级描边。
- Lock 说明只保留一句“每个仓库各自固定 Lock；不随分支移动。”
- 分支名过长截断，`title` 给完整值；路径允许折行。

### 8.3 任务与工作区

- TASK：任务名、状态、优先级、当前轮次；右侧“编辑”文字按钮。
- WORKSPACE：根目录（折行）、工作区分支（每个仓库一行）、状态（有未提交改动 / 干净）。
- 工作区分支行使用 mono，仓库名可截断，分支名不换行。
- 状态颜色：干净绿、有改动琥珀；不要只用颜色，要有文字。

### 8.4 模块、测试、成本

- MODULES：数量 + 模块路径/ID；空态“该项目没有配置模块。”
- TESTS：最近状态/耗时；空态“本次会话未执行测试。”
- COST / USAGE：2 列网格：
  - 未缓存输入
  - 输出
  - 缓存读写
  - 累计
  - 头部/底部 meta 用 `33.02M` 这类短格式。
- 所有区块默认展开；不折叠；只纵向滚动；没有横向滚动条。
- 320 宽度下标签不换行、ref 截断、路径换行；344 默认宽度下尽量一屏可读。

## 10. 看板

### 10.1 顶栏与工具栏

- 顶栏分段控件“工作台 / 看板”，看板选中。
- 指标行（mono）：卡片、进行中、活跃会话、待审核、已完成；数字用状态色。
- 过滤行：项目、版本、优先级、模块、搜索；右侧“项目 / 平铺”切换，默认项目分组。
- 指标和过滤不堆成两层大卡片；一条指标行 + 一条过滤行。

### 10.2 泳道与列

- 默认按项目分泳道；每个泳道固定五列：
  - 待开始（灰）
  - 进行中（蓝）
  - 待审核（紫）
  - 已完成（绿）
  - 失败（红）
- 空列保留，不能因为没卡片隐藏。
- 五列在 1440 内容区均分，不出现横向滚动；窄窗口列内换行，列宽继续均分。
- 泳道标题：文件夹图标 + 项目名 + 卡片数；右侧 `+ 新建卡片` 文字按钮。

### 10.3 卡片

- 标题最多两行；描述最多两行；可选。
- 元信息：版本 chip、优先级 chip；底部模块 + 会话数。
- 左侧 2px 状态色，和列头状态点一致。
- 卡片 hover 只加深边框/浅底，不放大；选中用蓝色边框或浅蓝底。
- 终态卡片（已完成）可降低描述对比度；失败卡片保留红色左线与失败文案。

### 10.4 拖拽

- 卡片可拖到另一列改状态。
- 只允许业务允许的移动：
  - 进行中 → 待审核 / 失败
  - 待审核 → 进行中 / 已完成 / 失败
- 非法目标不显示落点；拖动中卡片半透明；释放后失败要恢复并提示。
- 拖拽与点击区分：拖动后短时间内不触发打开任务。

### 10.5 右栏概览

- 标题：`BOARD / OVERVIEW` + 当前项目名。
- 统计：卡片、进行中、活跃会话、待审核。
- ACTIVE SESSIONS：运行中任务、版本、时间；绿点。
- REVIEW QUEUE：待审核任务、版本；紫点。
- PROJECTS：项目名 + 卡片数。
- RECENT ACTIVITY：时间 + 事件。
- 不放主按钮；看板主操作由顶栏新建/泳道新建承担。

### 10.6 空态

- 无任务：各列显示“暂无任务”，不是整板空白。
- 无项目：看板引导“新建项目”。
- 无筛选结果：显示“没有匹配的任务”+ 清除筛选。
- 右栏无会话时显示“暂无活跃会话”，不隐藏区块。

## 11. 状态、错误与空态

- **加载**：保留布局的骨架/浅灰；按钮 loading 文案；不要整页 spinner。
- **空**：每个区域一句具体说明 + 一个入口；不用大插画。
- **失败**：就近展示，保留用户输入；可展开技术详情；不弹 Toast 作为唯一反馈。
- **禁用**：保留轮廓和原因（Tooltip / 行内提示）；不要只降低透明度。
- **只读**：右栏分支、Lock、状态只读；不显示可点击的下拉箭头。
- **溢出**：长标题两行截断；长路径折行；分支单行截断 + title；数字 mono。
- **颜色**：状态必须带文字；错误/危险不能只靠红。

## 12. 响应式与可访问性

### 12.1 响应式

- 1440 是基准；1440 下五列看板、344 右栏、320 左栏必须完整。
- `>1180`：三栏完整；右栏默认 344，可拖到 460。
- `941–1180`：右栏 320–380；顶栏项目/版本保留；看板卡片元数据可减少。
- `≤940`：左栏抽屉；右栏限制在 300 左右或作为覆盖层；顶栏只留图标；看板仍不横向滚。
- 弹框：`max-width: calc(100vw - 32px)`；`max-height: calc(100vh - 32px)`；正文滚动，footer 固定。
- 不通过水平滚动解决布局；只允许代码 Diff 内容按自身换行设置滚动。

### 12.2 可访问性

- 图标按钮必须有 `aria-label` 和 Tooltip；纯图标不能承担唯一语义。
- 弹框使用 `role="dialog"` / `aria-modal`；打开时焦点进入，关闭后回到触发元素；Tab 循环。
- `Esc` 关闭；危险确认中 Esc 等同取消；请求中禁用。
- 状态、优先级、选中不能只靠颜色；有文字/图标。
- 点击区不小于 26×26；主按钮 36 高。
- `:focus-visible` 清楚可见；用 outline，不依赖 box-shadow。
- 遵循 `prefers-reduced-motion`；拖拽/弹框不需要动画才能理解。
- 表单 label 必须和输入关联；错误用 `role="alert"` 或 `aria-describedby`。

### 12.3 文案与 i18n

- 所有产品可见文案进入 `src/client/locales.ts` 的 `LoomKey`；组件通过 `t` 获取。
- 不在 JSX 中写中文/英文产品文案；动态数据（任务名、路径、分支、hash）保持原样。
- 术语统一：
  - 工作台 / 看板
  - 项目 / 版本 / 任务 / 模块
  - 工作区 / 分支 / 基线 / Lock / ref
  - 会话 / 回合 / 执行 / 接管
  - 进行中 / 待审核 / 已完成 / 失败 / 待开始
- 按钮用动词：新建、编辑、删除、开始执行、打开会话、生成 Lock、重新生成、停止并接管、丢弃改动并清理。
- i18n gate 必须通过：`node scripts/verify-client-ui-i18n.ts`。
